# Go Learning & Documentation Translations

**简体中文** | [English](README.en.md)

`go-tour-i18n` 是本项目保留的 legacy-stable 技术仓库名。项目公开名称为 **Go Learning & Documentation Translations（Go 学习与文档多语言本地化项目）**。

这是一个社区维护的非官方 Go 学习与文档多语言本地化项目。项目从 A Tour of Go 起步，现已扩展到站点 shell、Learn、Docs，并为 future content packages 使用同一套版本无关的 locale、统一术语、独立审核、校验与发布体系。

本项目不由 Google、Go 团队或 go.dev 官方维护，也不表示与官方项目存在隶属、授权、认可或背书关系。英文 source authority 来自 Go 官方内容；Site v2 / Learn / Docs 当前按仓库冻结的正式 source baseline 维护。

## 项目范围

当前采用 **Versionless Locale Architecture**：v1 / v2 / v3 是 implementation 或 content-package milestone，不是语言治理 namespace。每个 locale 持续沿用同一 identity、统一 glossary、Generation / Reviewer provenance 和历史可信成果。

当前正式内容范围包括：

- `tour-v1`：A Tour of Go，公开 canonical route 位于 `/tour/**`；
- `site-v2-shell`：本地化首页 `/` 与项目说明页 `/translation/`；
- `learn-docs-v1`：Learn、Tutorial、Database、Modules、Security；
- future content packages：按正式 source registry 增量接入，不另建独立语言治理体系。

每个 locale 永久只有一份 `locales/<locale>/glossary.yaml`。新增 package 时，可信且 unchanged 的旧成果继续 carry，只处理真实 new / stale / affected scope。

## 翻译与审核流程

正式语言工作不是“生成译文即完成”。核心流程为：

```text
Unified Glossary Generation / Refresh
→ Independent Unified Glossary Review
→ Structured Assets / TranslationUnit Generation
→ automatic validation
→ Independent TranslationUnit QC
→ exact revision / re-QC
→ A-only finalization
→ package closure
→ Integrated Surface Review
→ activation
→ Preview / Production
```

Generation 与 Reviewer 必须保持独立 session。Reviewer 只给 finding / rating / decision，不生成 replacement。Page、Example、structured assets、Surface 与 Production 的具体 gate 以当前正式 workflow / runbook 为准。

## 本地开发

需要当前仓库要求的 Go 工具链。从仓库根目录可启动本地 Tour runtime：

```bash
go run -mod=readonly ./tour -http 127.0.0.1:3999 -openbrowser=false
```

然后访问 <http://127.0.0.1:3999/tour/>。

> **安全警告：** 本地 Tour 的 `/socket` 会使用运行 Tour 的机器执行示例代码，只用于本地开发验证，应绑定回环地址，不得直接暴露到公网。Production runtime 使用正式远程执行链路，不在 Production 主机执行用户提交的 Go 程序。

Repository-level coding / docs 任务应按 [`AGENTS.md`](AGENTS.md) 运行与改动直接相关的 targeted tests；不要机械扩大为 repository-wide lifecycle test。
