Go Learning & Documentation Translations

Go is easier to learn when the explanations are accessible in your language. This community project localizes Go learning resources and documentation while keeping the canonical Go content as its reference.

What is included

Explore the interactive lessons and runnable examples in A Tour of Go, learning resources, and practical Go documentation. The project also localizes navigation, project information, and other shared site content. Future Go content can be added through the same translation and review process.

How translations are produced

  1. Work starts from the canonical Go source and a shared glossary for the language.
  2. Language models assist with generating translations from those inputs.
  3. Machine checks validate structure and protected details such as code, identifiers, and link targets.
  4. A separate language review checks meaning, clarity, and terminology. Findings return for focused revision and another review.
  5. Accepted content is checked together across the site, then goes through preview, maintainer checks, and release verification before publication.

Quality and independent review

Generating a translation and reviewing it are separate roles. The Reviewer does not write a replacement and then approve it; findings go back to the translation stage. Machine validation protects technical details, but it does not establish language quality. AI output is not published directly.

Revisions address the reported problem and matching instances within its scope. Another review checks that the problem has been resolved. These checks reduce mistakes, but translations can still contain errors, and reports from readers help improve them.

Ongoing maintenance

Each language uses one glossary across all surfaces. Source changes and reviewed glossary changes reopen only the affected content, with verified evidence for reuse of unaffected work.

Translations follow a recorded version of the canonical source. Updates to that source are checked to identify the content that needs attention. Changed content returns through the necessary translation and review steps; accepted unchanged work can be retained. The project is maintained over time.

Translations may differ from the latest official English website. Unavailable local pages link directly to the official source; direct requests to missing local pages return a real not-found response.
