Go Learning & Documentation Translations

This community project translates the Tour, Learn, and Go documentation. Future formal surfaces follow the same source, glossary, and independent review rules.

The official English source is the frozen golang/website baseline recorded in this repository. Local translations are activated only after generation, independent language review, and machine validation have passed for a complete package.

Each language uses one glossary across all surfaces. Source changes and reviewed glossary changes reopen only the affected content, with verified evidence for reuse of unaffected work.

The project homepage and this page have no advertising. Tour advertising follows the locale publication agreement; documentation advertising follows the explicit site policy.

Translations may differ from the latest official English website. Unavailable local pages link directly to the official source; direct requests to missing local pages return a real not-found response.

Local coverage

A language can have different completion states for the Tour, documentation, and shared site content. The site's language directory uses validated local coverage; a language name alone does not promise that every page is available locally.

Feedback and contributions

Use the project issue tracker to report a translation problem or discuss a contribution. Include the language, page, and relevant text so the problem can be located. A community reference link is not evidence that a formal upstream application has been submitted.

Generation and independent review

Generation uses the canonical source and the language's reviewed glossary. Machine validation checks protected identities and structure. An independent Reviewer judges the language; the Generation session does not approve its own output.

Reviewer findings return to Generation for a focused revision. A successor review checks that each finding category has been closed within its authorized scope. A content package can be finalized only when all of its formal translation units have an A rating.

From completed content to release

Package closure binds the finalized translations and required shared language assets. Integrated Surface review checks their combination. Locale activation selects validated coverage; it does not replace language review.

A fresh Preview and automated acceptance checks are followed by the maintainer's human check. Production publication is a separate step and does not turn unfinished or unreviewed content into completed translations.

Ongoing maintenance

Source and glossary changes are tracked through explicit identities and affected scopes. Verified unchanged work can be carried forward; affected work returns through validation and independent review. Historical generation and review evidence is preserved rather than rewritten.
