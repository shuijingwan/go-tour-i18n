### F02 — stable index 108 — `example:concurrency/exercise-web-crawler.go` — B

**English source comments:**

> // Fetch returns the body of URL and
> // a slice of URLs found on that page.

> // Crawl uses fetcher to recursively crawl
> // pages starting with url, to a maximum of depth.

**Exact Finnish candidate comments:**

> // Fetch palauttaa sivun URL sisällön sekä
> // viipaleen sivulta löytyvistä URL-osoitteista.

> // Crawl käyttää fetcher-muuttujaa ja käy rekursiivisesti läpi
> // sivut alkaen url-osoitteesta enintään depth-syvyyteen asti.

**Finding:** `sivun URL sisällön` uses an unnatural and ambiguous noun relationship, making the body of the web page corresponding to URL less explicit. The Crawl wording `alkaen url-osoitteesta enintään depth-syvyyteen asti` is understandable but cumbersome and redundant. The algorithm, code, URLs, types, depth bound, fetch error behavior, and all other machine semantics are preserved; this is a B-level precision/naturalness defect, not an algorithmic mistranslation.

**Required revision direction (Generation only):** Clearly distinguish the requested URL from the retrieved page body and the slice of URLs found on that page. Express recursive crawling from url with a maximum depth naturally in Finnish; keep Fetch, Crawl, fetcher, url, depth and every Go identifier, code line, machine comment and file layout unchanged. Independent Reviewer does not provide replacement.
